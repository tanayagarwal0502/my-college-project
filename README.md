# Music Suggestion System (Final-Year Project Version)

An intelligent, full-stack music recommendation and playback application powered by **Python Flask**, **MySQL**, and semantic sentence embeddings (**Sentence-Transformers**).

---

## 1. Overview of Features

- **Authentication & Security**: Complete User Registration and Login flow with input validation, duplicate prevention, and secure password hashing using `werkzeug.security`.
- **Profile Onboarding**: First-time users are guided to customize their favorite vibes (10 distinct moods) and upload a custom avatar (or skip with the default avatar).
- **Semantic Music Recommendation**: Users enter natural-language mood requests (e.g., *"I need something energetic for my workout"* or *"Mujhe romantic gaane sunne hain"* in English, Hindi, and Hinglish), and the system retrieves and ranks matching songs using cosine similarity over **768-dimensional sentence embeddings** generated by the primary **Model: `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`**.
- **Embedding Cache Optimization**: High-performance in-memory and compressed disk caching for catalog song embeddings, regenerating only on catalog additions or text updates and automatically invalidating obsolete embeddings.
- **Local Audio Playback**: Plays actual local MP3 files directly via an integrated HTML5 / JS audio player (Play, Pause, Seek bar, Time, Volume control) with single-track enforcement.
- **Favorites Management**: Users can heart (🤍 / ❤️) any recommended song to save it directly into their MySQL favorites list, view all favorites on their dedicated profile page, and play them directly.
- **User Feedback & Dynamic Profile**: Users can Like, Dislike, Skip, and rate (1–5 stars) songs, updating their preference profile in MySQL in real time.
- **Dedicated Profile Management**: Users can view their avatar, join date, email, selected vibes, edit their username/vibes, update their profile photo, or reset to the default avatar.
- **Internal Admin Dashboard**: Accessible at `/admin` to monitor live MySQL tables (`users`, `songs`, `user_requests`, `feedback`, `user_profile`).

## 2. Requirements

- **Python**: 3.9 or higher (tested on Python 3.10+)
- **MySQL Server**: 8.0 or compatible running locally on port 3306
- Modern Web Browser (Chrome, Firefox, Edge)

---

## 3. Database Setup

Database credentials can be adjusted in `.env`:

```env
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=root
MYSQL_DB=music_recommendation_db
SECRET_KEY=music_recommender_secret_key_demo_2026
```

On startup, Flask automatically initializes:
- Database: `music_recommendation_db`
- Tables: `users`, `songs`, `user_preferences`, `user_favourites`, `user_requests`, `feedback`, `user_profile`
- 10 Bollywood songs with local MP3 links
- Default Demo User (`demouser`)

## 5. Running the Application

1. Activate your virtual environment:
   ```powershell
   .\venv\Scripts\activate
   ```
2. Install dependencies (if not already installed):
   ```powershell
   pip install -r requirements.txt
   ```
3. Start the Flask server:
   ```powershell
   python app.py
   ```
4. Access in your browser:
   - **Login**: [http://127.0.0.1:5000/login](http://127.0.0.1:5000/login)
   - **Sign Up**: [http://127.0.0.1:5000/signup](http://127.0.0.1:5000/signup)
   - **Home (Music Suggestions)**: [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
   - **User Profile**: [http://127.0.0.1:5000/profile](http://127.0.0.1:5000/profile)
   - **Admin Dashboard**: [http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin)
